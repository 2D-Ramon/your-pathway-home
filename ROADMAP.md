# Website roadmap

## Reality check: $0 budget

| Need | Free possible? | Notes |
|------|----------------|-------|
| Hosting | ✅ Yes | Cloudflare Pages / GitHub Pages / Vercel free |
| Domain | ⚠️ Subdomain free | Real `.com` usually ~$10–15/year |
| Site pages, tools, calculators | ✅ Yes | We build these |
| Homestead guides + county links | ✅ Yes | Public gov links |
| Forms → email | ✅ Limited | Formspree free tier / Web3Forms / Lofty forms |
| Forms → Lofty | ✅ If Lofty gives form URL/API | Need account access |
| Full Tulsa MLS IDX | ❌ Rarely free | Provider fees typical; check if Lofty includes IDX |
| reCAPTCHA alternative | ✅ Yes | Honeypot + Turnstile |

**v1 strategy:** Ship a full branded site on free hosting with all content pages + tools. Wire **Home Search** to Lofty/MLS as soon as we have a free or included feed; until then use strong CTAs + temporary search embed if available.

---

## Phase 1 — Foundation (start now, $0)

- Brand shell (nav, footer, mobile)
- Home, About, Contact
- Buy process + Sell process
- Resources / tools (calculators, checklists, net sheet educational)
- Homestead page (guide + multi-county official links)
- Neighborhoods stubs (Tulsa metro)
- Fair housing / privacy / licensing
- Lead forms (honeypot; thank-you page)
- Placeholder / CTA for IDX search

## Phase 2 — Leads & Lofty

- Connect Lofty forms / valuation / chat
- Thank-you + notification path
- Optional saved-search messaging once IDX live

## Phase 3 — IDX live

- Choose provider (prefer whatever is free/included with Lofty or MLS)
- MLS approval of site
- Map search, alerts, branding + disclaimers

## Phase 4 — Growth

- Testimonials with real links
- Blog posts as needed
- Recruiting page (agents any state)
- Analytics (free: Plausible trial / GA / Cloudflare)
